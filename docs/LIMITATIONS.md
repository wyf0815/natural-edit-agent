# v9.8 已知限制

## 自动选区不是万能抠图

MobileSAM 根据框和点生成二值候选，遇到以下情况常需要人工修正：目标很小、目标与背景相似、多个对象接触、严重遮挡、反光或主观边界。高置信度也不保证像素边缘绝对正确。

v9.8 会先自动定位，并始终允许点选、面板自由套索或 Photoshop 原生工具修正。低置信度必须修正或明确接受；无有效候选不能继续。

## Photoshop 原生选择能力有公开接口缺口

- “选择主体”可通过当前使用的 Photoshop 描述符调用。
- `selection.subject_region` 是选择主体后与搜索范围求交，不是对象选择。
- Photoshop 的对象选择、选择人物和选择并遮住在不同版本、语言和文档模式下没有一套稳定公开的 UXP 自动化接口。
- 因此 v9.8 不会伪装成已经自动调用这些 UI。用户可在画布中使用原生工具，完成后回到面板采用当前选区。
- 发丝、毛发、烟雾、玻璃、透明和半透明边缘仍应使用选择并遮住、调整边缘或 Refine Hair；MobileSAM 只提供粗候选。

## Photoshop 版本和文档模式

项目主要面向 Photoshop 2026、RGB 8 位文档。Photoshop 2024/2025、CMYK、索引色、智能对象、锁定图层、特殊字体和第三方滤镜可能走不同描述符或拒绝操作。Node 回归通过不能替代 Photoshop 实机验证。

## 批注截图对应关系

红框、箭头、圈选等空间批注会先在本机用特征点和边缘模板与当前合成画面比较；支持等比缩放、少量批注覆盖，以及截图中带有 Photoshop 外框的常见情况。不匹配或无法证明对应关系时会停止并要求重新截取当前画面。严重裁剪、大片遮挡、纯色或特征极少的画面可能产生保守拒绝，但不会在无法确认时继续套用坐标。

## 模型和厂商差异

模型 ID、视觉输入、JSON 模式、速率限制、配额和数据政策会变化。厂商适配层只统一请求格式，不能保证账号拥有某个模型，也不能让上游错误自动变成安全的 Photoshop 修改。

## 本地明文秘密

插件设置中的 API Key、`config.local.json` 中的 API Key，以及桥接令牌文件目前都是本机明文。安装/启动脚本会尽量限制桥接令牌 ACL，但没有使用 Windows Credential Manager 或系统密钥库。共享账号、多人共用 Windows 会话或已被恶意软件控制的机器不在安全假设内。

## 不是生成式图像模型

本项目负责理解并调用 Photoshop 工具，不提供生成式填充模型本身。生成、补画或复杂内容移除取决于 Photoshop 已安装且可调用的能力。
