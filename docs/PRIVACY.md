# v9.8 隐私说明

## 本机处理

- Photoshop 文档结构由 UXP 插件读取。
- MobileSAM 分割在本机 Python 进程运行。
- 分割临时文件、缓存和请求日志保存在本机运行目录并被 Git 忽略。
- 模型文件保存在本机 `models` 并被 Git 忽略。
- 桥接令牌保存在 `%LOCALAPPDATA%\PhotoshopNaturalAgent\v9.8`，首次升级时可从 v9.7 或 v9.5 的有效令牌迁移，并以生成的脚本形式写入已安装插件目录。

## 可能发送给模型厂商的内容

- 用户的自然语言指令；
- 脱敏后的文档结构摘要；
- 任务需要视觉定位或复核时，当前合成画面的缩略图或用户提供的批注图。

模型厂商可能记录请求，且保存、训练和跨境政策各不相同。处理客户或保密素材前必须阅读所选厂商条款；不允许上传时，只使用本地且确定性的 Photoshop 能力。

## 明文存储说明

当前插件可能把 API Key 存在 UXP `localStorage`；桥接服务也可能从本机环境变量或 `config.local.json` 读取 API Key。桥接令牌 JSON 与已安装插件中的 `bridge-token.js` 也是明文。Windows ACL 只能降低其他本机账号误读风险，不能替代系统凭据保险库，也不能抵抗当前用户会话中的恶意程序。

不要把真实 API Key、桥接令牌、`config.local.json`、日志、PSD、客户图片或带有隐私内容的截图放进 Issue、聊天记录或 Git 提交。
